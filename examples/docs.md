# Acme Widget Docs

Demo fixture for GrantMilestone. NOT a real product's docs: a small doc set
used so Studio verification runs can fetch real deliverable material.

## Setup

Install with `npm install -g acme-widget`, then run `acme init`.

## Usage

`acme new <project>` scaffolds a project. `acme sync` uploads your notes.
